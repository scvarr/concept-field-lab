Инженерное завершение M021 не означает независимой визуальной приёмки. Семантическую полноту, истинность знания и применимость контекста тесты не доказывают; автоматического понимания текста/отождествления и межгруппового сопоставления нет. После checkpoint — **остановка**. Следующий конечный шаг принадлежит независимому оператору: новая изолированная SQLite по [инструкции](operator-guide.md), ручная визуальная проверка текста, графа, привязок, знаний и удаления/восстановления. Дальнейшую разработку автоматически не продолжать. Для идентификации checkpoint: `git log -1 codex/radical-cleanup`; состояние синхронизации: `git rev-parse HEAD origin/codex/radical-cleanup`.
