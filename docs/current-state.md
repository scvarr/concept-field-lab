## Выполнено

Конечный шаг M001 завершён по [плану](manual/implementation-plan.md). Реализованы локальный сервер Python, SQLite и графический браузерный интерфейс. Оператор может создать независимые исследования, рекурсивно раскрывать произвольные элементы, редактировать содержание / альтернативы / источники, использовать свободные типы связей, повторное использование, циклы и несвязанные части. Граф поддерживает выбор, поиск, масштаб, перемещение и сохранение позиций; большие структуры изучаются ограниченными окружениями и страничными списками.

Сопоставление показывает выбранные пары, равные / различающиеся поля, кандидатов по названию и ручные подтверждения / отклонения с обоснованиями. Отождествление не производится по названию. Выборочное объединение создаёт новое исследование с новыми ID, полными снимками происхождения и всеми исходными отношениями; оригиналы сохраняются. Изменения смысловой структуры требуют повторной проверки её соответствий.

[JSON v1](manual/data-format.md) поддерживает исследования целиком, окружение произвольной глубины, разницу версий / независимых структур и кандидатов изменений ChatGPT. Импорт сохраняет исходные ID, выявляет повторы, конфликты `base` и коллизии. Применение выбранного пакета атомарно. Все исходные документы и существенные изменения сохраняются; компактная история экспорта восстанавливает каждую версию. Рабочая база хранит сжатые снимки и optimistic revision для защиты от устаревших вкладок. Принято [ADR M001](manual/architecture.md).

## Восстановление работы

Для оператора, Windows **cmd.exe**:

```bat
cd /d E:\Projects\concept-field-lab
start.cmd
```

Требуются Python 3.11+ и браузер; установка библиотек не нужна. URL — `http://127.0.0.1:8765`, база по умолчанию — `local-data\workspace.sqlite3`. Каталог базы игнорируется Git. Закрытие / повторное открытие с той же базой сохраняет работу. [Инструкция оператора](manual/user-guide.md) описывает резервные копии, перенос, очередь кандидатов и варианты запуска.

Для разработчика:

```bat
python -m unittest discover -s tests -v
python -m scripts.benchmark_workbench
node --check app/static/app.js
git diff --check
```

Браузерная проверка требует Node.js, Playwright 1.62.1 и установленного Chrome; команды в отчёте. Тесты используют свои временные базы и не заполняют пользовательскую базу демонстрациями. Незавершённых тестовых запусков нет. Checkpoint сохраняется commit и push в рабочую ветку; подтверждение синхронизации — `git status --short --branch` и совпадение `git rev-parse HEAD` / `git rev-parse origin/codex/manual-knowledge-tool`. Main не объединять.

## Ограничения и следующий конечный шаг

Критерий автономной ручной работы выполнен на проверенном сценарии без изменения кода / файлов данных. Не проведена человеческая проверка удобства в длительной ежедневной работе; это не препятствует использованию готового интерфейса. Не заявлена производительность за пределами проверенного графа. История SQLite увеличивается со временем, предел импорта — 64 МиБ; для большего объёма доступны исследования, фрагменты и пакеты. Сервер локальный, без совместной сетевой работы и семантического решателя.

Следующий конечный шаг — external review ветки до merge: пройти операторский сценарий на двух собственных независимых исследованиях, проверить смысл выбора соответствий и удобство интерфейса. Завершение — замечания по конкретным операциям и решение reviewer; предел — один проход до 30 минут, два исследования до 20 элементов каждое. Семантические решения остаются за человеком. Дополнительную научную цель не начинать без согласования.
