# Действующая архитектура

Браузер → локальный HTTP-сервер → операции над снимком → полная валидация → транзакция SQLite. Backend использует стандартную библиотеку Python. Сборки frontend нет; сервер отдаёт JS/CSS из `app/static`.

| Модуль | Назначение |
| --- | --- |
| `app/server.py` | Loopback HTTP, token/Origin/Host, ресурсы, preview и действия |
| `app/permanent.py` | Один постоянный граф, валидация, журнал, импорт/экспорт и restore |
| `app/store.py`, `app/journal.py` | Общие проверки/кодирование и компактная история JSON Patch |
| `app/graph_editor.py`, `app/designations.py`, `app/alpha.py` | Атомарные правки графа, обозначения и обязательный состав α |
| `app/thoughts.py`, `app/element_bindings.py` | Разборы, конструкции, фрагменты, привязки, номера и включение в знания |
| `app/scenes.py` | Сцены, экземпляры/утверждения, доступность знаний, рабочие копии и контекстные переходы |
| `app/lifecycle.py` | Каталог зависимостей, preview удаления и сброс |
| `app/permanent_geometry.py` | Координаты, сохранение/возврат раскладки и закрепление |

В браузере `workspace.js` связывает три вида и обмен; `thoughts.js` — единственный интерактивный путь создания сценических элементов. `scenes.js` показывает знания, связи сцен и рабочие копии; `management.js` управляет зависимостями. Постоянный граф редактируется через `graph-editor.js`, включая вызовы из разбора. Один `graph-view.js` рисует оба вида; `canvas-menu.js`, `alpha-captions.js` и `overview-geometry.js` обслуживают меню, подписи и геометрию.

`permanent-layout.js` запускает `layout-worker.js`/`layout-engine.js` на отделённой копии координат. D3 и Dagre в `static/vendor` сохранены как фактические зависимости раскладки вместе с лицензиями. Результат применяется отдельной подтверждённой транзакцией.

HTTP: GET `/api/state`, `/api/history`, `/api/export`, `/api/manage-index`; POST `/api/graph-preview`, `/api/manage-preview`, `/api/import-preview`, `/api/action`. Изменения требуют token, допустимых Host/Origin и текущей revision. SQLite хранит сжатые JSON-снимки; API отдаёт обычный JSON. История включает граф, разборы и сцены.

Старые исследования, слияние источников, очередь предложений, конструктор определений, внешние словарные загрузки, `--legacy` и `?compat=...` удалены. Автоматических миграций и альтернативного редактора сценических объектов нет.
