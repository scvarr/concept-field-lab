# Шаг 003: контекстно условный оператор

Протокол до измерения качества. Мотив: шаг 002 выявил 14 отказов из-за недоступной выбранной роли, исправляемых простым object-first.

## Вопрос и механизм

H3: роль-контроллер, приобретаемая с учётом наличия basic аргументов, переносится на новые сочетания не хуже заданного object-first в пределах 2 п.п. и лучше unconditional лексического majority. Это проверка приобретения **условия оператора**; лингвистические категории и само семейство связывания предоставлены исследователем.

Контекстная сигнатура: четыре бинарных признака наличия nsubj/obj/iobj/obl у parent и один признак того, что сам parent имеет basic отношение xcomp. Никаких enhanced признаков на входе. Обучающая роль выводится из предоставленного gold тем же способом, что в шаге 002.

Варианты: global signature majority и lexical+signature. Первый использует наиболее частую train роль в сигнатуре, откат — global majority. Второй смешивает счётчики (lemma,signature) с четырьмя псевдонаблюдениями распределения по signature; если signature неизвестна — global distribution. Фиксированная сила 4, без подбора. Исполнитель тот же рекурсивный basic graph binding. Контроли заново обучаются: память пар, global majority, lexical majority; также заданные subject-only и object-first.

## Проверка и независимость

Все 615 документов original SynTagRus train получают fold=int(SHA256('003:'+document_id),16)%5. Для каждого fold остальные документы — только train, этот fold — только оценка. Все обучаемые контроли переобучаются. Точные совпадения текста с обучающей частью исключаются. Исходные dev/test не используются и не входят в новый подбор.

Важно: это внутренний cross-validation на корпусе, который ранее использовался как обучение; это **не новый источник, не untouched confirmation и не независимая человеческая семантика**. Новые параметры постановки выбраны после просмотра шага 002, но до измерения этих folds. Исходный test не переоценивается для улучшенного механизма.

Метрики и интерфейс шага 002 сохранены. Основной срез — новые пары при известных обеих леммах относительно конкретного fold-train; минимум 100 наблюдений. H3 локально поддержана, если global signature даёт ≥3 п.п. сверх lexical majority с положительной нижней bootstrap границей и нижняя граница разницы с object-first ≥−2 п.п. Порог не объявляется универсальным критерием полезности системы. Lexical+signature — объявленная дополнительная альтернатива, не замена основной гипотезы.

Парный bootstrap по документам 2 000 повторений, seed=20261009. Интервал условен на уже обученных fold-моделях; перекрытие их train частей не учитывается повторным обучением bootstrap. Сохранить оценки каждого fold, чтобы видеть вариативность.

## Завершение и ресурсы

Пять fold-запусков, одна фиксированная версия; только уже загруженные данные, Python standard library, <2 ГБ RAM, <20 минут. Проверки на искусственных графах только для отсутствия утечки и исполнения, не доказательство H3. Завершение: воспроизводимые folds, приобретённые таблицы, все предсказания, сравнения, анализ отказов и решение о следующем конечном вопросе. При отрицательном результате не расширять параметры на этих же ответах.
