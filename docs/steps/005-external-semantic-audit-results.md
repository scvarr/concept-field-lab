# Шаг 005: внешний вспомогательный аудит

На 25 случаях с выраженным участником приобретённый global context-оператор совпал с замороженной LLM-оценкой в 22/25 при basic Taiga и 15/25 при автоматическом basic. Это небольшой exploratory аудит другого источника, **не независимый human-gold результат и не подтверждение общей семантики**.

## Порядок и качество свидетельства

Taiga test содержит 1 217 предложений и 15 440 токенов, ни одного непустого DEPS. Найдено 113 допустимых целей; фиксированным hash-выбором отобраны 40. Вход аннотатора содержал только формы с IDs и цель. Codex той же сессии назначил 25 clear, 14 без выраженного участника и 1 неоднозначный случай с клаузальным содержанием. Оценки вместе с причинами отправлены в Git checkpoint `c91988c` **до** исполнения шага 005. После предсказаний ответы не редактировались; canonical SHA256 записан в metrics JSON.

Отклонение протокола: обещанную изоляцию от операторных таблиц обеспечить в этой сессии нельзя — её история уже содержала некоторые таблицы и общий алгоритм предыдущих шагов. Для конкретных 40 целей были предъявлены только поверхностные формы, а их предсказания ещё не вычислялись; но это частичная слепота и возможное ожидание ответа, не независимый аннотатор. Уверенность clear — самооценка этой LLM, а не agreement нескольких людей. В 40 предложениях нет совпадения обучающих текстов наших операторов или parser; исключений нет. Смысл и источники аннотационной ошибки ещё требуют проверки независимым человеком. Замороженные оценки позволяют воспроизвести числа, но не обещают заново получить ту же LLM-разметку.

| Механизм | Basic Taiga, clear | Автоматический basic, clear |
|---|---:|---:|
| Subject-only | 18/25 (72%) | 13/25 (52%) |
| Object-first | 22/25 (88%) | 15/25 (60%) |
| Unconditional lexical | 20/25 (80%) | 14/25 (56%) |
| Acquired global context | 22/25 (88%) | 15/25 (60%) |

25 случаев соответствуют 21 группе по эвристике источника: для ненумерических sent_id удалён финальный `-номер`, numeric IDs считаются отдельными фрагментами. Это эвристика группировки, не доказательство 21 независимого документа. Доверительный интервал не используется для общей оценки такого малого LLM-размеченного среза.

## Ошибки и новые наблюдения

Три отказа при basic graph: `7099:23` (она умеет следить), `6759:10` (организм пытается продолжить род), `6145:10` (желатину дать набухнуть после залить). Во всех трёх выбранный parent не имеет собственного basic субъекта, а executor умеет наследовать только по xcomp. В первых двух случаях контекстный участник доступен через координацию; в рецепте материальный участник назван в предшествующем действии той же инструкции. Это проверяемый предел реализованного семейства операторов, не доказательство невозможности эпизодного связывания.

При автоматическом graph также встречаются неверные привязки: `39:10` выбрал ID=5 которого вместо ID=6 я; `4291:6` — чувство и год вместо тебе; в длинной исторической фразе `...encicl15-39:33` — письма вместо писцы. Это разногласия с LLM-оценкой, сохранённые для review; они не замаскированы исправлением ответов или выбором только удачных примеров.

По 15 nonclear случаям истинность не оценивалась. Basic context дал 15 отказов; parsed context построил одну связь `6881:16` к машине при просьбе сообщить автору информацию. Она отмечается как требующая семантического review, а не включается в автоматическую точность. Неявные участники, клаузы, отрицание и референция требуют другого интерфейса, чем только ID явно названного токена.

## Воспроизведение

```powershell
python scripts/prepare_external_audit.py
.venv/Scripts/python.exe scripts/external_semantic_audit.py
python scripts/verify_results.py
git diff --check
```

Вспомогательную разметку повторно не генерировать: использовать frozen `results/005/annotations.json`. Python 3.13.2, ufal.udpipe 1.4.0.1; 6.245 с. `data/external-sources.json` фиксирует источник и SHA256. `annotation-input.json` — чистый поверхностный вид; `predictions.jsonl` — все basic/parsed графы, предсказания и трассы; `metrics.json` — значения и fingerprint. Производные материалы Taiga: CC BY-SA 4.0, исходные attribution/license — `data/README.md` и raw README/LICENSE.

## Вывод шага

Внешний exploratory аудит согласуется с полезностью ограниченного структурного связывания и с зависимостью от качества parser. Он не доказывает открытой способности формировать новые осмысленные факты. Следующая **содержательно независимая** проверка этого вывода — слепой человеческий review замороженных 40 оценок и отложенный набор реальных эпизодов с общей сущностью между действиями. Простое добавление conj под уже увиденные три ошибки было бы разработкой по этим ошибкам; его успех на этих же 40 случаях нельзя называть независимой проверкой.
