Протокол до назначения вспомогательных ответов и исполнения механизма. Разведка источника уже установила отсутствие DEPS у Taiga test; качество связей не измерялось.

После исполнения: зафиксировано отклонение изоляции аннотатора — общая история сессии содержала операторные таблицы предыдущих шагов. Предсказания этих 40 целей появились только после frozen checkpoint, но полной слепоты не было. Подробности в отчёте; ниже сохранена исходная постановка.

## Вопрос

Согласуются ли построенные связи с прочтением другого набора реальных русскоязычных текстов, когда нет enhanced конвертера SynTagRus? Это exploratory проверка внешней переносимости и ошибок смысла, не confirmatory тест на human gold.

Источник Russian Taiga r2.17, revision d1e48cd29c1f19b6aad1aec361d9f724db764f66, test только. 40 целей xcomp VERB с parent VERB/AUX/ADJ и без прямого basic nsubj, выбираемых минимальным SHA256('005:'+sent_id+':'+token_id). Не фильтровать по будущим предсказаниям. 40 — предел содержательной разметки этого шага, без расширения после результата.

## Роль LLM и слепой порядок

Codex текущей сессии — **вспомогательный LLM-аннотатор**, не механизм связывания. Аннотатор получает поверхностные слова с IDs, конкретный целевой предикат и полный текст предложения, но не basic HEAD/DEPREL, не enhanced слой (его нет), не операторную таблицу или предсказания этих целей. Связи и неоднозначности фиксируются в JSON **до** запуска механизма и Git checkpoint. Этот порядок не является полным double-blind: аннотатор знает гипотезы и общий алгоритм из предыдущих шагов.

Для каждой цели: множество IDs выраженных в том же предложении участников, уверенность clear/ambiguous/no_overt_participant, краткая семантическая причина. Если субъект не выражен, нельзя придумывать сущность. При неоднозначности сохранить возможные альтернативы и не включать случай в основную exact-оценку. Определяется носитель действия/состояния в синтаксическом смысле, включая пациента пассивного предиката; агент пассива не подменяет его субъект.

Вспомогательные оценки не используются для переобучения/настройки. Числа условны на оценках LLM и не называются независимым подтверждением смысла. Материалы сохраняются для будущего слепого человеческого review; результаты не исправляются под предсказания. Воспроизводим механизм и замороженный набор оценок; повторное получение таких же оценок моделью не обещается.

## Исполнение, критерии и предел

Обучение той же global context-table из полного SynTagRus train, fixed family и параметры шага 003. Контроли subject-only, object-first, unconditional lexical. Оценить gold basic Taiga и автоматический UDPipe basic из форм с gold токенизацией. На clear с выраженным участником — exact set match; отказ и ошибка отдельно. По ambiguous/no_overt — показать ответы без оценки истинности.

Аудировать точное пересечение текста с обучением наших правил и parser; совпавшие случаи исключить только из итоговой внешней оценки с сохранением ID. Загрузки <10 МБ, 40 предложений разметки максимум, <5 минут вычисления, никаких платных сервисов. Завершение: фиксированный набор, оценки/альтернативы, все предсказания, ошибки и предел выводов. Не назначать универсальный порог успеха exploratory аудита; решение — требуется ли человеческая проверка и что остаётся непроверенным.
