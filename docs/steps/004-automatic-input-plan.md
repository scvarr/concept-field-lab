# Шаг 004: автоматическое структурирование наблюдения

Протокол до оценки качества. После шага 003 условные таблицы практически воспроизводят эвристику, но все выводы зависели от ручного basic разбора.

## Вопрос

H4: фиксированный приобретённый контекстный оператор сохраняет полезное качество при замене gold морфосинтаксиса автоматическим. Не учить и не выбирать модель parser по test. Бесплатный UDPipe 1.4.0.1 с готовой russian-syntagrus UD 2.5 моделью 191206 — **внешняя предварительная обработка**, не исследуемый механизм приобретения/связывания и не LLM. Его обучающие данные и схема представлены извне.

На вход parser только gold границы предложения/токенов и их поверхностные формы; леммы, POS, морфология, HEAD, DEPREL и DEPS очищены. Поэтому это автоматическая обработка **токенизированного текста**, а не полный raw-text end-to-end. Исполнитель получает только предсказанный basic граф, целевой enhanced слой скрыт.

## Проверка

Исходный SynTagRus test уже просмотрен в шагах 001/002; это явно обозначенная парная диагностика деградации интерфейса, не untouched confirmation нового механизма. Для parser дополнительно проверить отсутствие пересечения test ID, документов и текста с UD r2.5 train/dev, на которых согласно документации обучалась модель. При пересечении исключить затронутые документы; источник, бинарник, SHA256 и версия пакета фиксируются. Внешние документы без DEPS не использовать как фиктивный отрицательный ответ.

Из r2.17 train приобрести global context и lexical context с фиксированной силой 4 и базовые правила предыдущих шагов. На test с gold enhanced ответом оценить точное множество участников и micro P/R/F1 на **тех же целях** для gold basic и parsed basic; только аннотированные цели определяют качество. Невосстановленный xcomp считается отказом. Срез новых-known пар определяется по gold леммам лишь для оценки, не поступает в parser/исполнитель.

Контроли: subject-only, object-first, lexical majority; две условные таблицы. Параметры не выбираются заново. Сохранить parser LAS/UAS, долю восстановленных целевых xcomp, ошибки лемм/структуры и исходные результаты для парного сравнения.

H4 локально поддержана, если на ≥100 новых-known целях global context с parsed графом даёт exact ≥80% и деградация относительно gold basic не превышает 10 п.п. Оба порога — операционные для этого диагностического интерфейса; не критерий общего понимания. Интервалы разницы — document-bootstrap 2 000, seed=20261009. Если условие не выполнено, явно сохранить предел данного parser, не выбирать более сильный по тому же test.

## Ресурсы и завершение

До 300 МБ дополнительных загрузок, одна локальная небольшая parser-модель, <2 ГБ RAM, <20 минут обработки. `.venv` внутри проекта; никаких глобальных установок/платных API. Готовые модели приобретения знаний и LLM не используются. Завершение: аудит утечки, версии/хэши, все parsed входы и предсказания, метрики деградации и ограниченный научный вывод о входной зависимости.
