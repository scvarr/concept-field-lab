# Шаг 002: результат связывания

Новые субъектные связи строятся из текущего графа и приобретённых правил без запоминания целой пары действий. Однако более простая заданная эвристика оказалась лучше лексического majority-правила. Формальный основной критерий H2 относительно отказывающейся на новых парах памяти выполнен; это слабый контроль и не доказывает преимущество приобретённых лексических правил.

## Приобретение и оценка

В train 11 701 допустимая xcomp-цель. У 4 285 нет enhanced субъектного ответа; 534 аннотированных случая не дают однозначной роли из объявленного семейства. По 6 882 пригодным наблюдениям приобретены 257 лексических операторов и 4 675 операторов точных пар. Глобальные счётчики: nsubj=6 349, iobj=311, obj=222, obl=0. Никакие enhanced связи не входят в исполняемый тестовый граф.

| Механизм | Всё test (911) | Новая пара, известные леммы (453) | Глубина ≥2 (8) |
|---|---:|---:|---:|
| Память точной пары с отказом | 39.41% | 0.00% | 0/8 |
| Глобальное правило / всегда субъект | 86.61% | 82.56% | 5/8 |
| Заданное obj→iobj→nsubj с рекурсией | **92.54%** | **92.94%** | **8/8** |
| Приобретённое правило без рекурсии | 90.23% | 89.40% | 1/8 |
| Приобретённое правило с рекурсией | 90.89% | 90.29% | 7/8 |

Точность — exact set match IDs участников; не точность выбора слова. У рекурсивной модели на всём test micro precision=94.95%, recall=90.48%, F1=92.66%. 911 аннотированных целей находятся в 62 независимых от train документах; новых-known целей — 453 в 59 документах.

Парные разницы на новых-known: против глобального правила +7.73 п.п. (95% CI +2.92…+12.56); против заданного object-first −2.65 п.п. (−5.18…−0.48); против своего нерекурсивного варианта +0.88 п.п. (0.00…+1.98). Bootstrap 2 000, seed=20261009, по документам. Наблюдения глубины ≥2 слишком малочисленны для общего вывода (8<30); 7/8 не доказательство неограниченного композиционного переноса.

В test всего 1 436 целей, из них 525 не имеют enhanced ответа. Для 122 таких целей модель построила связь, но качество этих связей неизвестно; они не объявляются ложноположительными или правильными. Отчётное качество условно на наличии целевого слоя. GSD не используется, поскольку в нём отсутствует DEPS.

## Проверяемые конструкции и ограничения

`2003Armeniya.xml_84:14`: новая пара начать→ухудшаться связывает текущего участника ID=4. `2013ES-ofshor.xml_28:7`: для закрыть правило оставаться→nsubj рекурсивно применяет мочь→nsubj и связывает ID=2; трасса и весь basic граф сохранены. Это новый экземпляр отношения между токенами, не новое фактическое утверждение о мире.

Операторы вроде заставить→obj и позволить→iobj приобретаются из наблюдаемых связей. Majority по одной лемме теряет условие наличия соответствующего аргумента и возможные варианты конструкции. Аудит 83 exact-ошибок: 20 отказов, 20 случаев с пропущенным gold-участником на basic conj; категории пересекаются. В 14 отказах object-first правильно связывает доступный аргумент. Object-first исправляет 18 ошибок модели и портит 3 её правильных ответа. Ещё одна вероятная причина — расхождение basic местоимения с enhanced антецедентом; она пока не посчитана. Это структурная диагностика, не независимая оценка смысла.

Независимость: train/test разделены по документам, предсказания вычисляются без DEPS. Но сама целевая разметка произведена конверсией исходного корпуса; точная история каждого ребра не установлена. Предоставленный xcomp уже сообщает наличие обязательного контроля. Поэтому эксперимент показывает исполнимость и перенос связывания **при предоставленной лингвистической структуре**; самостоятельное открытие категорий/правил из сырого текста и человеческая осмысленность ещё не проверены.

Семь проверок прошли, включая отсутствие DEPS в графе исполнения, привязку объекта на новой паре, сохранение результата при переименовании/перестановке IDs и разрыв вывода после удаления опорной дуги.

## Следующий вопрос

Эвристика использует доступность аргументов, а majority-правило использует только лемму. Проверить, можно ли **приобрести условный оператор по структуре доступных аргументов** и достигнуть качества этой эвристики. Чтобы не подбирать механизм на просмотренном test, следующий протокол должен использовать документные folds внутри исходного train с заново обученными контролями. Это новый внутренний диагностический эксперимент, не независимая семантическая репликация.
