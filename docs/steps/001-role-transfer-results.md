# Шаг 001: результат

H1 не подтверждена по заранее заданному критерию. Прирост переноса на SynTagRus test составляет 2.24 п.п.; парный 95% bootstrap-интервал по документам −0.71…+5.24 п.п. Требовались ≥3 п.п. и положительная нижняя граница.

Train: 69 631 предложение, 65 119 ролевых дуг, 7 124 полные тройки, 8 564 существительных, 5 883 глагола, 3 546 достаточно поддержанных профилей. На dev выбраны k=50 и сила переноса=1 из объявленной сетки. Test не использовался при выборе. 615 train-документов не пересекаются по ID с dev/test; 5 dev-троек с совпадающим train-текстом исключены, test-совпадений нет.

В GSD недостаточно примеров для обещанной независимой проверки (38<100), IDs документов отсутствуют: bootstrap группирует только предложения. Его отрицательная точечная разница −7.89 п.п. не доказывает обратный эффект, но не поддерживает устойчивость улучшения.

## Что наблюдается и чего не следует заключать

На 468 новых парах 276 примеров имеют хотя бы одну поддержанную цепочку переноса. 30 ошибок общей роли исправлены, 19 правильных назначений испорчены, одна ничья стала ошибкой; 22 ничьи сохранились. Значительная часть качества уже объясняется общей лексической склонностью быть подлежащим. На одной новой паре почти весь прирост даёт память другой пары.

Примеры исправлений (ID → глагол, подлежащее, объект): `2008Bezrabotnye.xml_10:14` → волновать, престижность, количество; `2003Bolshie_peremeny.xml_55:10` → окончить, ребенок, класс. Примеры ухудшения: `2003Armeniya.xml_7:11` → играть, диаспора, место; `2003Bolshie_peremeny.xml_7:6` → принести, год, перемена. Это проверяемые разногласия с разметкой, а не человеческая оценка бессмысленности перестановки. Полные локальные входы и предсказания сохранены в JSONL.

Отдельная опасность: лексические предпочтения не различают разные события с теми же словами и могут выбирать частый смысл вместо фактического контекста. Порог частоты ограничивает редкие леммы; нет внешних классов и контекстного разрешения многозначности. Ручная разметка даёт единицы наблюдения извне. Проверка не доказывает самостоятельное извлечение знаний из сырого текста, генерацию истинных утверждений или превосходство «поля» над статистикой.

## Воспроизведение

Python 3.13.2, Windows 10; только стандартная библиотека. Источник и SHA256 каждого файла — `data/sources.json`; 157.4 МБ исходников приблизительно. Команды из корня:

```powershell
python scripts/fetch_ud.py
python -m unittest discover -s tests -v
python scripts/role_transfer.py
git diff --check
```

Полный эксперимент занял 2.863 с на данной машине. Bootstrap: 2 000 повторений, seed=20261009, resampling документов с сохранением числа примеров в выбранном документе. Ничьи считаются 0.5. `results/001/metrics.json` содержит все категории, поддержку и параметры; `*_predictions.jsonl` позволяет пересчитать результаты. Время и строка ОС могут меняться при повторе, предсказания детерминированы.

TF-IDF: (1+ln count)×(1+ln((N+1)/(df+1))), затем L2-нормировка. Перенос оценивает долю nsubj среди взвешенных косинусом ролей k соседей при целевом глаголе; смешивается с наблюдениями пары и одним псевдонаблюдением общей роли. Если соседей с этим глаголом нет — откат к памяти пары. Назначение двух аргументов сравнивает совместные произведения вероятностей; знак разницы эквивалентен p(nsubj|s)−p(nsubj|o).

## Решение о продолжении

Не увеличивать сетку на уже просмотренном test и не объявлять успех графового механизма. Следующий информативный вопрос — связывание участников в конкретном контексте и вычисление новой связи через вложенные действия. Можно проверить на тех же реальных текстах с отдельной целевой разметкой enhanced UD; понадобится явно учесть зависимость этой разметки от конвертера. Это новый вопрос, а не повтор неудачного подбора соседей.
