# Запуск и работа оператора

Требуются Python 3.11+ и браузер. Из корня проекта:

```powershell
python -m app.server --db local-data/clean-workspace.sqlite3
# Отдельная база и порт для независимой визуальной проверки:
python -m app.server --no-browser --port 8766 --db local-data/operator-review.sqlite3
```

Откройте `http://127.0.0.1:8765` (или указанный порт). Остановка — Ctrl+C. `start.cmd` передаёт те же параметры. Путь по умолчанию — `local-data/workspace.sqlite3`; для чистого запуска передайте новый `--db` явно. Старые базы и JSON v1–v6 не мигрируют.

1. В «Динамическом» создайте сцену и фразу. Выделите фрагмент и выберите структурный элемент/роль и содержание. Постоянные концепты и ребро привязки можно создать через общий preview либо выбрать по существующим ID.
2. Элемент отображается как `Винт (Объект 1)`. Повторная привязка фрагмента не создаёт дубликат; новый независимый объект задаётся явно. Для продолжения прежнего объекта выберите его сценический ID в поиске. Содержательный концепт не получает номер экземпляра.
3. Добавьте отношения между элементами и, при необходимости, направленные разрешения между использованиями рёбер. Доступное продолжение выполняется отдельной командой. Значение/обязательность, привязка и снятие элемента редактируются интерактивно.
4. Покройте значимые фрагменты, проверьте необходимые связи и подтвердите содержание. Заполненный шаблон сам этого подтверждения не даёт. Завершите мысль как состояние или событие.
5. По желанию включите завершённую мысль в выбранную или новую сцену знаний. Постоянные концепты общие, экземпляры независимы. Конструкцию можно сохранить и применить с другой фразой; изменение обязательной структуры требует явного уточнения.

«Знания» показывает сцены, экземпляры, входы и ссылки. Новая мысль открывает тот же редактор текста. Для использования знания в разговоре задайте контекст/доступные ссылки, создайте рабочую область и явно извлеките заполнения. Извлечение не активирует все связи; seed и продолжение задаются отдельно. Смена контекста не переписывает копии.

«Постоянный» позволяет искать и редактировать концепты, обозначения, обычные рёбра и разрешения. Изменение группы использует тот же редактор; раскладка меняет координаты после отдельного подтверждения. Скрытие полотна не удаляет данные.

«Управление данными» показывает preview удаления и зависимости. Выберите зависимые записи явно, пересчитайте preview и подтвердите. Полный сброс сохраняет журнал. «История и обмен» экспортирует v7, показывает preview импорта и восстанавливает версию всего состояния. Перед опасной правкой скачайте экспорт; восстановление не стирает более позднюю историю.

При ошибке сохранения оставайтесь во вкладке: локальный ввод можно восстановить в редактор. При конфликте revision обновите состояние и повторно проверьте изменения. Инженерные проверки:

```powershell
python -m unittest discover -s tests -p "test_*.py" -q
node --test tests/test_*.cjs
# Только для браузерного теста:
npm install --no-save --package-lock=false --ignore-scripts playwright@1.64.1
node tests/scene-elements-browser.cjs
```

Браузерный тест использует установленный Chrome, новую SQLite в `test-output` и отдельный процесс сервера. Автоматические сценарии не заменяют независимую визуальную оценку удобства.
