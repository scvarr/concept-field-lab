# ADR M005: накопительное полотно и происхождение маршрутов

Дата: 12 октября 2026. Статус: принято для инженерной реализации M005; семантическое тождество остаётся решением оператора. Дополняет M001/M002/M004.

## Контекст

Прежний merge создаёт третье исследование для пары графов, но не продолжает одно полотно, не проверяет отказы при последующей транзитивности и не отделяет составное окружение от обхода рёбер разных источников. Пользователь требует накопление произвольного числа графов, индекс совпадений и несколько независимых инспекторов. K001/K002 не изменяются.

## Решение

Накопление — отдельное исследование с неизменяемыми снимками добавленных источников, журналом решений и материализованной проекцией. Ручные confirmed образуют классы эквивалентности исходных представлений; rejected сохраняются как ограничения между классами, pending не объединяет. Новый шаг проверяет все прежние отказы после транзитивного замыкания; противоречие отклоняет транзакцию целиком. Добавление исходника сохраняет прежние ID, координаты и решения. Исходные исследования не удаляются. Их последующие правки не меняют ранее захваченный снимок автоматически.

Каждое исходное ребро получает собственный ID копии и полный origin с исходным ID / снимком; сохраняются направление, type, структурная функция и дополнительные атрибуты. Рёбра не дедуплицируются после слияния концов, в том числе петли и параллельные рёбра. Объединённый узел сохраняет все исходные представления. Корни источников доступны как rootIds; прежний rootId служит только совместимым якорем обычного инструмента, не ограничивает накопление одним корнем.

Кандидаты вычисляются по явно выбранному словарю или техническим названиям и не входят в study.edges. Источники обозначений не смешиваются даже в режиме «оба»: источник каждого совпадения указан. Текстовый индекс хранит точные количества исходных совпадений / решений; визуальные пары ограничены отдельно. Для исходников без словаря оператор может добавить обозначение в рабочий словарь накопления — без изменения исходного исследования и без автоматического преобразования названий в словарь.

Обход инспектора выполняется отдельно в каждом исходном снимке, затем результаты проецируются на объединённые узлы. Совместный показ — объединение этих независимо полученных окрестностей, без общего обхода на смешанных рёбрах и без кандидатов. Цвета / подписи источников временно различают маршруты; они не реализуют семантику контекстных рёбер. Основная камера и координаты сохраняются в базе / JSON, локальные камеры инспекторов и настройки индекса относятся к состоянию оператора.

JSON v3 сохраняет и проверяет снимки, карты объектов, журнал решений, рабочие обозначения и материализацию. Чтение v1/v2 сохраняется, старые SQLite-снимки не переписываются. Прежние версии приложения явно отвергают новый JSON, вместо молчаливого редактирования накопления без его инвариантов. Самостоятельный экспорт накопления не требует наличия исходных исследований в принимающей базе: их полные представления уже сохранены. Решения импортируемого накопления сохраняются как часть просмотренного производного артефакта; обычные внешние matches по-прежнему требуют review.

## Альтернативы и последствия

Повторять прежний merge для очередных пар — потеря рабочего пространства / координат, трудная проверка отказов. Мутировать исходные исследования — нарушение независимости и происхождения. Дедуплицировать рёбра по концам — потеря исходных утверждений. Скрыто добавить новые инварианты к v2 — прежний клиент мог бы редактировать новое накопление как обычный граф. Новый renderer / графовая библиотека — не необходимы для выбранной конечной границы; расширяется действующий GraphView.

Цена решения: снимки дублируют исходное содержание и увеличивают SQLite-историю / JSON; предел обмена остаётся 64 МиБ. Содержательные правки производного графа блокируются, возможны решения, рабочий словарь и координаты. Снимок источника не обновляется автоматически. Частичные экспорты накопления пока запрещены, чтобы не нарушить классы / ограничения; инспекторы не требуют такого экспорта. Пересмотр уже принятого отождествления доступен через штатное восстановление версии истории, локальное разотождествление не реализуется в M005. Производительность сверх измеренного набора не заявляется.
