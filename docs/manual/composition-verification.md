## Наблюдаемые результаты

**37 автоматических тестов прошли**: 24 прежних и 13 предметных ([журнал](evidence/composition/unit-tests.txt)). Проверены:

- собственная идентичность анонимных α / β, необязательные имя / содержательный тип, направленное включение, вложенность, повторное использование и циклы;
- внешнее утверждение только о целом и отсутствие вывода / отождествления из общего компонента;
- перенос входящих / исходящих / компонентных ссылок с прежними ID, корня, обозначений, происхождения и соответствий; необходимость повторной проверки последних;
- неподтверждённое / неоднозначное замещение, пустой состав, самоопределение, самоссылки и столкновение соответствий: отказ без частичной записи;
- локальная отмена, отказ после изменения контекста и точное восстановление полной версии истории;
- v1-импорт / SQLite без переписывания старого снимка; v2 round-trip с историей, словарём, следом замещения, повторный импорт без дублей и фрагмент глубины 0;
- различение компонента и содержательной связи в diff; архивный перенос словаря / замещения в объединение; обратный diff с явным кандидатом удаления записи;
- отказ неполного импортированного контекста; детерминированный пример и массовый импорт 2 000 компонентов.

**Новый браузерный сценарий прошёл** ([отчёт](evidence/composition/browser-report.json)). Созданы анонимная α, компоненты «твёрдость», модификатор и «свойство», внешняя связь X → α, β → α и другая комбинация с общим «свойство». Пройден X → β → α → компонент и возврат: версия и полное состояние до / после навигации совпали. Подтверждено замещение «твёрдый» → α, проверены внешние связи, исходный снимок и словарь; отмена восстановила исходные узлы и связи. После повторного замещения и изменения α отмена дала ожидаемую ошибку HTTP 400 без записи. Preview самоопределения показал препятствия без кнопки подтверждения.

Через GUI выполнены v2-экспорт, повторный импорт без кандидатов, полное восстановление истории туда / обратно, новый процесс сервера, v2-импорт в чистую базу и v1-импорт двух независимых исследований. Исходные ID сохранены; повторов нет. Пустые имена комбинаций не породили кандидатов соответствия. После повторного запуска редактирование продолжилось. JavaScript ошибок нет; один HTTP 400 — ожидаемая проверка безопасного отказа. Большая комбинация импортирована 4 002 кандидатами: обзор — 15 элементов, карточка — 60 связей, список — 80 элементов; последний компонент найден по ID и попал в граф. Высота графа / страницы ограничена и проверена. Принятие кандидата удаления открытой комбинации очистило устаревший контекст и вернуло корень без ошибок.

**Прежний браузерный сценарий прошёл повторно** ([отчёт](evidence/composition/regression-browser-report.json)): создание «камень» / «камня», рекурсия / цикл, сопоставление, подтверждение / отклонение, объединение, экспорт / буфер обмена, кандидаты ChatGPT / конфликт / отказ, история, новый процесс и продолжение, 5 000 узлов / 10 000 связей, массовое принятие 15 001 кандидата, поиск, черновик и ширина 1 000 px. ## Визуальная проверка и исправленные попытки

Проверены реальные снимки [β / α](evidence/composition/nested-composition.png), [замещения](evidence/composition/substitution.png), [большого состава](evidence/composition/large-composition.png). Подписи и элементы управления читаемы, состав отличается пунктиром, контекст доступен над графом. Полный снимок происхождения раскрывается в карточке.

Первая новая браузерная проверка посчитала ожидаемый HTTP 400 JavaScript-ошибкой; тест исправлен так, чтобы отдельно проверять ровно один ожидаемый отказ и отсутствие иных ошибок. Для генератора большого JSON увеличен ограниченный буфер subprocess до 16 МиБ: стандартный буфер был меньше документа, приложение здесь не участвовало. Benchmark сначала вызван как файл и не нашёл пакет `app`; корректная команда — `python -m scripts.benchmark_workbench`.

Визуальная проверка обнаружила растягивание SVG на десятки тысяч пикселей при большом составе: процентная высота не имела ограниченного контейнера. Панель получила фиксируемую по окну высоту; обзор состава ограничен 14 компонентами в двух колонках, выбранный компонент включается обязательно. Полные данные доступны поиском и страницами. Добавлены проверки высоты, выполнены повторно оба браузерных сценария. Это инженерное ограничение отображения, не ограничение глубины или размера данных. Дополнительная проверка быстрого последовательного импорта выявила гонку отрисовки очереди: выбор мог выполняться до завершения её загрузки. Теперь действия очереди недоступны во время загрузки, устаревшие ответы не применяются. После этого повторно прошли оба браузерных сценария.

## Граница результата

Операторские действия доступны без изменения кода / JSON-файлов. Семантическую эквивалентность и выбор переносимых утверждений решает человек. Инструмент переносит все показанные ссылки на целое только после подтверждения; неоднозначные случаи не угадывает. Локальная отмена требует неизменного затронутого контекста, включая соответствия исследования; иначе доступна полная история. В импортированном фрагменте контекст замещения может включать объекты вне фрагмента: это сохраняет происхождение, но не обещает локальную отмену без полного графа. Обратный diff не стирает накопленные origins.

Путь навигации живёт только во вкладке и начинается заново после её перезагрузки. Производительность сверх 5 000 узлов / 10 000 связей и 2 000 компонентов здесь не измерялась. Долгосрочное удобство ежедневной работы требует external review оператором; автоматические сценарии не заменяют такую оценку. Семантический вывод, поиск маршрутов, активация, обучение и генерация не реализованы.
