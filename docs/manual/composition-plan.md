# M002–M003: ручное исследование составных концептов

Основа: `codex/manual-knowledge-tool`, `9d4fdaf`; 9 октября 2026. Согласованная граница — анонимные комбинации, включение компонентов, контекстный интерфейс, словарные обозначения и подтверждаемое замещение. Старые исследования интеллекта не используются. Никаких семантических выводов из связности, автоматической эквивалентности, обучения и генерации.

## M002: модель и обмен

Вопрос: можно ли добавить самостоятельные анонимные комбинации и обратимое замещение, сохраняя старые графы, ID, происхождение и журнал?

Способ: расширить существующую модель необязательными структурными полями и словарём; JSON v2 с чтением v1 без переписывания старых снимков; атомарная операция замещения с проверкой неоднозначных ссылок и журналом затронутого контекста. Проверить регрессии, импорт / экспорт, восстановление, изоляцию, общий компонент без ложного переноса внешних утверждений и отказ небезопасного замещения.

Критерий завершения: автоматические проверки проходят, v1 сохраняет исходные данные, v2 восстанавливает комбинации / словарь / след замещения; неоднозначности дают ошибку без частичной записи. Предел: стандартная библиотека, синтетические графы до 30 элементов для предметных случаев и прежний масштабный тест 5 000 / 10 000; без пользовательских семантических решений за человека. Checkpoint — документация, проверки, diff-check, commit и push.

## M003: интерфейс и операторские случаи

Вопрос: можно ли практически работать с β, содержащей α, входить в состав и возвращаться к X, привязывать обозначение и подтверждать / отменять замещение через GUI?

Способ: доработать текущие карточки, граф и навигацию; отдельный браузерный сценарий всех случаев пользователя, затем прежний браузерный сценарий как регрессия. Возврат хранится только в состоянии интерфейса, без семантического ребра.

Критерий завершения: все заявленные действия доступны без изменения кода / файлов данных, после перезапуска сохранены структуры и словарь, экспорт / импорт работает. Предел: два локальных браузерных сценария и визуальная проверка, бесплатная установленная среда, без переписывания сервера / хранения. Результаты, ограничения замещения, команды и ближайший шаг — в документации и `current-state.md`; commit и push, без merge.
