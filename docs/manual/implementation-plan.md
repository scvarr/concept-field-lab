# Конечный шаг M001: ручной инструмент

Дата: 9 октября 2026. Согласованная цель — локальный инструмент ручного рекурсивного раскрытия и сопоставления знаний. Старые научные гипотезы и механизмы не используются.

Вопрос: может ли оператор без редактирования кода и файлов данных пройти создание двух независимых исследований, рекурсивное раскрытие с повторным использованием и циклом, ручное сопоставление, выборочное объединение и продолжение после перезапуска?

Способ: приложение Python/SQLite и браузерный интерфейс, проверки операций хранения и HTTP, отдельный автоматизированный браузерный сценарий с синтетическими данными «камень»/«камня». Проверки происхождения, сохранения конфликтующих пояснений, отклонённых соответствий, экспорт/импорт и восстановления истории.

Критерий завершения: все операции сценария доступны через GUI, данные сохраняются после нового процесса сервера; тесты проходят; инструкция cmd.exe позволяет запустить приложение без сборки интерфейса. Названия не служат основанием для автоматического отождествления.

Предел ресурсов: один конечный шаг реализации и проверки; стандартная библиотека Python в приложении, локальные бесплатные средства тестирования; синтетические небольшие графы и масштабный тест 5 000 элементов / 10 000 отношений с ограниченной отрисовкой окружения; без платных сервисов, обучения, агентов и автоматической генерации знаний. Семантическую истинность тестовых структур не проверяем. По дополнительному требованию включены полные исследования, фрагменты произвольной глубины, различия, стабильные ID, повторный импорт и рассмотрение конфликтов / предложений ChatGPT.

Результаты и ограничения фиксируются в `verification.md`, состояние продолжения — в `../current-state.md`.
