## Что изменилось и с чего продолжать

**Оператор не принял первоначальный K003** из `69a1c24`: 38 многословных имён и содержательные пояснения подменяли структуру. Старый [nut.json](../../data/experiments/nut/nut.json), его история / аудит / проверки сохранены неизменными как исторические свидетельства. K001 изучен как методический ориентир однословных существительных / выраженных путей / отсутствия скрытого текста; его схема не копировалась, соответствия по словам не принимались.

В `codex/k003-concept-revision` создан **отдельный K003r** — [nut-revised.json](../../data/experiments/nut/nut-revised.json), версия 137: **45 концептов / 0 α / 45 связей**, полностью новые ID. Все имена — однословные существительные в именительном падеже, сверенные вручную. Содержательные notes, kind, alternatives, type и componentRole пусты; source только о происхождении, внешний словарь содержит «гайка». Масса / форма / цвет / материал проверены независимо и восстановлены: неспецифичность не причина удаления. 52 кандидата до группировки и review всех прежних 42 узлов — [revision-audit.json](../../data/experiments/nut/revision-audit.json) / [revision-inventory.json](../../data/experiments/nut/revision-inventory.json).

Два прежних контекстных трения заменены обращениями к общим концептам: `опора → контакт → трение` и `резьба → контакт → трение`. Входы различают области рассмотрения; общий ID не является ID конкретного контакта или утверждением тождества двух участий. Конкретные локальные значения и привязка свойств к участию не выражены.

**Не решены** номинальная / средняя роли диаметра, длина фактического зацепления, силовые / инструментальные роли, зазоры двух частей, сопротивление отвинчиванию / срезу / коррозии / износу. Общая длина не заменяет длину зацепления; коррозия — изменение, её сопротивление в графе отсутствует. Три предложения α отклонены: набор компонентов не задаёт требуемую привязку. Смысловые потери сохранены явно, не спрятаны в пояснения.

Прошли 22 проверки записи / покрытия аудита / обмена / истории и 6 GUI-сценариев, включая пустую карточку, общее окружение контакта, точный export / повтор / restore / новый сервер. Старый K003 и исходное двухисточниковое полотно в изолированной базе сохранились. Это не независимое доказательство семантики; оператор K003r ещё не принял.

**Следующее действие — операторский просмотр нового графа по концептам и окружениям**, без нового автономного цикла. Для отдельного открытия сохранить резервную копию, импортировать `nut-revised.json` через «Обмен и кандидаты» / review 92 объектов, выбрать «Гайка — K003r» в «Исследования». Семантические решения и добавление источника — отдельная операторская работа.

## Сохраняемые различия

- Слово — внешнее обозначение / возможный вход, не сама структура. Одно слово может адресовать несколько структур, одна структура — несколько обозначений. Узел с ID может служить входом без имени; корни K001/K002 пока допустимы, удалять / заменять их α не требуется.
- Декомпозиция снизу вверх: сначала разнообразные элементы, затем обоснованные общности. Для именованных концептов предпочтительно одно существительное; многословный смысл требует структурного исследования. Не терять различие удалением слов и не назначать заранее обязательную классификацию. Листья не доказаны атомами.
- α — осмысленный состав / повторное использование, не обязательная замена входа или выполнение. Компонентность не доказывает применимость, альтернативность и привязку свойства. Длинный текст в словаре / notes также не заменяет структуру.
- Будущее уточнение изолированного ввода или удержание нескольких кандидатов при чтении — гипотезы. Сцена может ограничивать выбор процессного / предметного чтения передачи; роли / выбор ещё не исследованы и в K002 задним числом не вводятся.
- Накопление добавляет независимые подграфы без автоматического тождества. Словарное / техническое совпадение — кандидат; оператор подтверждает тождество, различие или неопределённость. Рёбра / происхождение остаются раздельными после объединения; смешанный маршрут не подтверждается. Контекстные связи именно между рёбрами — открытый вопрос.
- Достижимость не приписывает свойство или значение. Неуказанное неопределённо; не создавать удобное `камень → мокрый` в обход структуры. Различать непосредственную активацию, контекстный выбор, дополнительный вывод, концепт и участие. Отсутствие выражаемого маршрута фиксировать ограничением.

K001: 29/28 без α, преимущественно физические характеристики, не полное определение камня. K002: 35 концептов + 2 α / 38 связей, 11 чтений; полнота / эквивалентность не доказаны. Эти графы не меняются. Динамические активации, маски, сцены, автоматический выбор / вывод не реализованы; ответы LLM не проверяют механизм. UX без постоянных подписей рёбер из `4828b6f` сохранён, метаданные / правка / α / происхождение / кандидаты доступны. История пересмотров — [chronology.md](chronology.md); дальнейшие изменения — отдельная ветка и external review перед merge.
