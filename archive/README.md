Отдельное прежнее исследование перенесено сюда как исторический снимок, без новой научной проверки и без принятия его цели для продолжения.

Эти документы описывают **прошлое состояние той ветки**, не актуальную цель или инструкции проекта. Старые AGENTS применяются только к архивному дереву в рамках действующих пользовательских указаний; корневая работа продолжает использовать корневой AGENTS.md.

Единственный действующий навигатор — [docs/README.md](../docs/README.md), актуальное состояние — [docs/current-state.md](../docs/current-state.md). Архивный `docs/README.md` — сохранённый старый указатель, не второй общий навигатор. Новое исследование по архивной цели не начинается автоматически. Семантические выводы и первичные данные не пересматриваются при переносе.

Проверка архивных тестов из корня: `python -m unittest discover -s archive/observational-composition/tests -v`. Для полного повторения экспериментов перейти в каталог снимка и использовать его исторические команды / источники; ignored raw-данные и optional UDPipe не включены в Git и требуют отдельного восстановления. В рамках объединения они не скачивались и предсказания не перегенерировались.

При интеграции использованы уже существовавшие локальные raw-входы после проверки всех 20 размеров / SHA256 и существующая корневая `.venv`: `.venv/Scripts/python.exe -m unittest discover -s archive/observational-composition/tests -v` — 11 успешных проверок; `.venv/Scripts/python.exe archive/observational-composition/scripts/verify_results.py` подтвердил все 20 хэшей и сохранённые метрики. Эти ignored локальные копии не являются частью снимка Git; на чистом клоне восстановление остаётся отдельным действием.
