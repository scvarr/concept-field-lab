# Шаг 004: результат автоматического входа

H4 не подтверждена: точность на новых-known сочетаниях 81.24% превышает объявленные 80%, но потеря против gold basic составляет 11.70 п.п., больше разрешённых 10 п.п. Исследуемый оператор исполняется без gold морфологии/синтаксиса, однако качество заметно зависит от внешнего анализатора.

## Парные результаты

Те же 453 новые-known цели в 59 test-документах. Приобретённая global context-table: gold basic=92.94%, parsed basic=81.24%; paired CI для parsed−gold: −14.80…−8.86 п.п. На всех 911 annotated целях: 92.54%→79.47%, разница −13.06 п.п., CI −15.49…−10.82. Parsed micro P=89.06%, R=79.25%, F1=83.87% на всём срезе. Conditional table и заданный object-first здесь дают одинаковые ответы.

| Parsed механизм | Exact все annotated | Exact новая пара known |
|---|---:|---:|
| Subject-only | 74.97% | 73.51% |
| Object-first / acquired global context | 79.47% | 81.24% |
| Unconditional lexical | 78.16% | 79.25% |
| Lexical context | 78.81% | 79.91% |

Parser обработал 1 296 предложений с 1 436 целями и 30 046 токенами; это выбранные предложения с xcomp, не весь test. Lemma=96.34%, POS=95.98%, UAS=87.65%, LAS=80.85%. 1 355/1 436 целевых отношений остались xcomp, 1 344/1 436 сохранили также gold parent. Потеря качества не сводится к потере xcomp: ошибки других опорных дуг, лемм и структуры также попадают в исполнение.

## Аудит независимости и внешнего знания

UD r2.5 train+dev parser: 55 398 предложений в 569 документах. Пересечение с r2.17 test по ID предложений и документов равно нулю. 23 точных совпадения текстов есть во всём test; среди предложений выбранных xcomp-целей таких совпадений нет, поэтому целевые случаи не исключались. Script всё равно исключает любой совпадающий текст или документ. Model SHA256 и URL immutable mirror, исторические данные для аудита — `data/parser-sources.json`.

UDPipe 1.4.0.1, russian-syntagrus UD 2.5 191206; модель предоставляет уже выученную морфологию и базовый синтаксис. Это допустимая внешняя предварительная обработка, **не результат нашего обучения**. На вход идут только формы и gold границы токенов/предложений, все остальные поля пусты. Тест проверяет чувствительность фиксированного механизма, а не обучает его на ошибочных/сырых наблюдениях. Цели оценки всё ещё выбираются по gold xcomp; это не end-to-end detection/relation extraction benchmark.

Исходный test был просмотрен ранее, поэтому новый результат — диагностика интерфейса, не untouched confirmation. Зависимость gold enhanced от конвертера сохраняется. 525 целей без enhanced ответа остаются неоценёнными. Это предел текущего parser/оператора, а не опровержение всех способов автоматического приобретения знаний.

## Воспроизведение

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install --only-binary=:all: -r requirements-parser.txt
python scripts/fetch_parser.py
.venv/Scripts/python.exe -m unittest discover -s tests -v
.venv/Scripts/python.exe scripts/automatic_input.py
git diff --check
```

Python 3.13.2, 11 тестов прошли, эксперимент 14.744 с. Дополнительные исходники и модель — около 138 МБ; пакет менее 1 МБ. `results/004/parsed_input.conllu` позволяет проверить автоматические графы, JSONL — предсказания и трассы, metrics JSON — аудит, качество и интервалы. Производные данные SynTagRus и модель имеют CC BY-NC-SA 4.0; UDPipe library MPL 2.0. По [документации модели](https://ufal.mff.cuni.cz/udpipe/1/models) использовано исходное train/dev/test-разбиение UD 2.5, а не все данные.

## Следующий вопрос

Качество ещё проверялось относительно одного конвертированного целевого слоя. Разведочная проверка Russian Taiga r2.17 показала отсутствие DEPS у всех 15 440 test-токенов. Это отсутствие ответа, не отрицательный семантический результат. Можно провести конечный небольшой внешний аудит смысла на Taiga с заранее замороженными вспомогательными LLM-оценками и отдельно сохранить их неопределённость; такие оценки не заменяют независимого человека и не входят в обучение механизма.
