# Шаг 003: результат условного оператора

Структурное условие выбора роли можно приобрести из наблюдений: global context-table почти воспроизводит заданный object-first. Но основной критерий H3 полностью не выполнен: эффект относительно unconditional lexical=+1.96 п.п., меньше объявленных 3 п.п., хотя нижняя граница интервала положительна. Утверждать полный успех H3 нельзя.

## Измерения

Пять документных folds original train. 12 целей с точным train-текстом исключены. 7 406 целей имеют enhanced ответ; основной новый-known срез содержит 3 832 цели в 578 документах.

| Механизм | Всё annotated | Новая пара known | Глубина ≥2 (68) |
|---|---:|---:|---:|
| Точная память пары | 36.65% | 0.00% | 8.82% |
| Global majority / subject-only | 85.51% | 81.92% | 35.29% |
| Заданный object-first | 90.47% | 89.54% | 95.59% |
| Unconditional lexical recursive | 89.12% | 87.53% | 91.18% |
| Приобретённый global context | 90.44% | 89.48% | 95.59% |
| Приобретённый lexical context | 90.40% | 89.41% | 95.59% |

Global context − lexical majority: +1.96 п.п., CI +1.25…+2.64. Global context − object-first: −0.052 п.п., CI −0.232…+0.104. Последний удовлетворяет объявленной диагностической границе −2 п.п. Lexical context не даёт преимущества над global context: −0.078 п.п., CI −0.363…+0.204. Bootstrap по документам условен на фиксированных fold-моделях; train части пересекаются и не переобучаются в bootstrap.

Global context на основном срезе по fold: 89.39%, 90.38%, 91.23%, 86.47%, 89.87%. Различие качества между документными наборами больше различия с object-first. Глубоких целей 68 вместо 8 в original test, но они всё ещё происходят из одного корпуса, с теми же аннотационными правилами.

## Что приобретено

Например, в fold 0 сигнатура `10100` (субъект и iobj есть, obj и obl нет, parent не xcomp) имеет iobj=111, nsubj=54 и выбирает iobj. `10000` имеет nsubj=3 867 и выбирает nsubj. `11000` имеет obj=63, nsubj=49 и выбирает obj. Таблица сохраняет конфликты наблюдений, а не объявляет правило без исключений.

Из семейства доступных операторов система приобрела **условие выбора** по структуре эпизода. Она не открыла самостоятельно xcomp или рекурсивное связывание: эти операции заданы исследователем. Не потребовались устойчивые лексические классы существительных, поле активации или отдельный оператор для каждого сочетания действий. Это ограниченное свидетельство полезности разделения общей процедуры связывания и статистически приобретаемой таблицы её условий.

Словарь условий в этой задаче проще лексической модели и даёт практически качество эвристики. Преимущество сверх эвристики не обнаружено. Нельзя переносить эти числа на открытое понимание текста, планирование действий, произвольную глубину или генерацию утверждений.
