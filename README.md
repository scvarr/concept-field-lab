# Concept Field Lab

Локальный инструмент ручного исследования концептуальных структур: один постоянный граф, динамический разбор текста и сцены знаний. Смысл, экземпляры, связи и разрешения выбирает оператор. Автоматического понимания текста нет.

Python 3.11+ и современный браузер. Для работы не нужны npm, pip, словарные загрузки и внешние сервисы.

```powershell
python -m app.server --db local-data/clean-workspace.sqlite3
```

Адрес: `http://127.0.0.1:8765`. Для отдельной проверки задайте новый путь SQLite; прежние базы автоматически не преобразуются. `start.cmd` передаёт те же параметры. Остановка — Ctrl+C.
