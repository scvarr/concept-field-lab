# concept-field-lab

Независимый исследовательский проект приобретения структурированных знаний и их использования в новых сочетаниях. Цель — качество доказательств, включая отрицательные результаты; архитектура заранее не предписана.

[Навигатор документов](docs/README.md) описывает назначение рабочих материалов. Правила Codex находятся в [AGENTS.md](AGENTS.md), состояние работы — в [docs/current-state.md](docs/current-state.md).

Проведены пять конечных шагов: ролевые предпочтения, приобретение связывания, контекстные условия, автоматический вход и внешний вспомогательный аудит Taiga. [Научный вывод](docs/research-findings.md): ограниченный механизм связывания жизнеспособен при предоставленном лингвистическом представлении; широкая способность самостоятельно приобретать и строить осмысленные знания остаётся неопределённой. Отрицательные результаты и границы сохранены.

Для первых трёх шагов нужен Python 3.13 и стандартная библиотека; для двух последующих — небольшой бесплатный UDPipe в локальной `.venv`. Команды/параметры в отчётах, источники и лицензии — в [описании данных](data/README.md). `python scripts/verify_results.py` независимо проверяет хэши источников и арифметику всех сохранённых метрик. Все предсказания и трассы хранятся в `results/`; вспомогательные LLM-оценки заморожены до запуска и не используются в обучении.
