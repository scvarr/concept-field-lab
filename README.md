# concept-field-lab — Поле знаний

Локальный инструмент ручного рекурсивного раскрытия и сопоставления структур знаний. Создавайте независимые исследования, раскрывайте любые узлы, работайте со свободными типами отношений и циклами, вручную подтверждайте соответствия и объединяйте выбранные элементы с сохранением происхождения. Во вкладке «Единое полотно» можно постепенно собирать несколько исходных графов, рассматривать словарные совпадения в индексе и сравнивать независимые окружения узлов. Анонимные комбинации α имеют собственную идентичность и вложенные компоненты; словарь и подтверждаемое замещение позволяют сохранять слово как обозначение структуры.

## Запуск в Windows cmd.exe

Нужен Python 3.11+ и браузер. Дополнительные библиотеки и сборка не нужны.

```bat
cd /d E:\Projects\concept-field-lab
start.cmd
```

Откроется `http://127.0.0.1:8765`. Данные сохраняются в `local-data\workspace.sqlite3`; следующий запуск продолжает работу. Для остановки — Ctrl+C. Можно использовать `start.cmd --port 8766` или `py -3 -m app.server`.

[Инструкция оператора](docs/manual/user-guide.md) описывает построение, единое полотно, сопоставление, обмен, рассмотрение кандидатов, восстановление и резервные копии. [JSON v3](docs/manual/data-format-v3.md) переносит накопительные полотна со снимками источников и решениями; прежние [JSON v2](docs/manual/data-format-v2.md) и v1 читаются при импорте. ID сохраняются при импорте; повторные данные не дублируются; конфликты требуют решения. Прежнее разовое объединение двух исследований также доступно.

## Проверки

[UX M004](docs/manual/ux-research.md): большая рабочая область, сохраняемые камера/выбор, непрерывное движение узлов и рёбер, два независимых вида и раздельные кандидаты по словарю/названиям. [ADR вида](docs/manual/ux-architecture.md) описывает границу SVG и рассмотренные Canvas/WebGL. Для геометрических проверок: `node --test tests/test_graph_view.cjs`; обычный запуск приложения по-прежнему требует только Python и браузер.

Ручное [исследование «камня»](data/experiments/stone/stone.json) (K001) можно импортировать в существующий редактор: 29 однословных концептов / 28 связей, один маршрут к каждой позиции описания, без значений экземпляров. Это исследовательское предложение; функции, отвергнутые варианты и ограничения — [§12 заключения](docs/discussion/conclusion.md), проверки и оценка редактора — в [дополнении отчёта](docs/manual/composition-verification.md). Актуальное продолжение хранится только в [current-state.md](docs/current-state.md).

Независимое [исследование «передачи»](data/experiments/transfer/transfer.json) (K002, 12 октября 2026): проверена релевантность 84 кандидатов, сохранены 35 постоянных концептов + 2 α / 38 связей. Чтения различены без схем участников и выполнения; реляционное ядро и сложные листья ограничивают полноту. Принятые / отвергнутые общности и сравнение с K001 без отождествления — [§13 заключения](docs/discussion/conclusion.md), проверки записи / GUI-обмена — в [отчёте редактора](docs/manual/composition-verification.md).

[Начальное накопительное полотно K001+K002](data/experiments/accumulation/k001-k002-workspace.json) — переносимый JSON v3 с двумя независимыми исходными графами и нулём решений об отождествлении. Его можно импортировать через «Обмен и кандидаты» и продолжить во вкладке «Единое полотно»; он не меняет канонические K001/K002.

```bat
python -m unittest discover -s tests -v
python -m scripts.benchmark_workbench
git diff --check
```

Браузерный сценарий и условия воспроизведения — в [отчёте составных концептов](docs/manual/composition-verification.md) и [исходном отчёте](docs/manual/verification.md). Синтетический [пример «камень» / «камня»](data/fixtures/manual-example.json) можно импортировать через GUI. Его содержание не подтверждено и не является научным результатом. На масштабном наборе проверены 5 000 узлов / 10 000 отношений, массовый импорт, ограниченная визуализация, история и повторное открытие. Проверена также комбинация с 2 000 компонентами. [Пример составов](data/fixtures/composition-example.json) можно просмотреть / принять через очередь импорта. Неоднозначное замещение отклоняется; локальная отмена возможна до изменения затронутого контекста, полная версия остаётся в истории.

Реализация ограничена ручным инструментом. Интеллект, генерация, обучение, маршрутизация и динамика активации не реализованы и не проверены. [Заключение обсуждения](docs/discussion/conclusion.md) отдельно фиксирует гипотезы о сценах, активациях и контекстных маршрутах; [журнал пересмотров](docs/discussion/chronology.md) сохраняет развитие идей. База редактора M004 находится в main; новое накопительное полотно подготовлено в экспериментальной ветке и требует external review перед merge.
