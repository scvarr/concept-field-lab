# concept-field-lab

Независимый исследовательский проект приобретения структурированных знаний и их использования в новых сочетаниях. Цель — качество доказательств, включая отрицательные результаты; архитектура заранее не предписана.

[Навигатор документов](docs/README.md) описывает назначение рабочих материалов. Правила Codex находятся в [AGENTS.md](AGENTS.md), состояние работы — в [docs/current-state.md](docs/current-state.md).

Первый воспроизводимый эксперимент — перенос ролевых предпочтений на реальных русскоязычных текстах UD. Его гипотеза не подтверждена по объявленному критерию; [отчёт](docs/steps/001-role-transfer-results.md) отделяет наблюдения от выводов. Для воспроизведения нужен Python 3.13 и стандартная библиотека; команды и лицензии приведены в отчёте и [описании данных](data/README.md).
