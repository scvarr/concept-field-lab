# concept-field-lab — Поле знаний

Локальный инструмент ручного рекурсивного раскрытия и сопоставления структур знаний. Создавайте независимые исследования, раскрывайте любые узлы, работайте со свободными типами отношений и циклами, вручную подтверждайте соответствия и объединяйте выбранные элементы с сохранением происхождения. Анонимные комбинации α имеют собственную идентичность и вложенные компоненты; словарь и подтверждаемое замещение позволяют сохранять слово как обозначение структуры.

## Запуск в Windows cmd.exe

Нужен Python 3.11+ и браузер. Дополнительные библиотеки и сборка не нужны.

```bat
cd /d E:\Projects\concept-field-lab
start.cmd
```

Откроется `http://127.0.0.1:8765`. Данные сохраняются в `local-data\workspace.sqlite3`; следующий запуск продолжает работу. Для остановки — Ctrl+C. Можно использовать `start.cmd --port 8766` или `py -3 -m app.server`.

[Инструкция оператора](docs/manual/user-guide.md) описывает построение, сопоставление, обмен с ChatGPT, рассмотрение кандидатов, восстановление и резервные копии. [JSON v2](docs/manual/data-format-v2.md) (импорт v1 совместим) поддерживает целые исследования, окружения произвольной глубины, различия и предложения изменений. ID сохраняются при импорте; повторные данные не дублируются; конфликты требуют решения. Объединение создаёт третье исследование с исходными снимками.

## Проверки

```bat
python -m unittest discover -s tests -v
python -m scripts.benchmark_workbench
git diff --check
```

Браузерный сценарий и условия воспроизведения — в [отчёте составных концептов](docs/manual/composition-verification.md) и [исходном отчёте](docs/manual/verification.md). Синтетический [пример «камень» / «камня»](data/fixtures/manual-example.json) можно импортировать через GUI. Его содержание не подтверждено и не является научным результатом. На масштабном наборе проверены 5 000 узлов / 10 000 отношений, массовый импорт, ограниченная визуализация, история и повторное открытие. Проверена также комбинация с 2 000 компонентами. [Пример составов](data/fixtures/composition-example.json) можно просмотреть / принять через очередь импорта. Неоднозначное замещение отклоняется; локальная отмена возможна до изменения затронутого контекста, полная версия остаётся в истории.

Текущая цель ограничена ручным инструментом. Интеллект, генерация, обучение, маршрутизация и динамика активации не исследуются. Рабочая ветка создана от `origin/main`; merge требует external review.
