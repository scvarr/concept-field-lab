# Concept Field Lab — один постоянный концептуальный граф

Локальное приложение ручного исследования внутреннего языка. Конструктор определений и постоянный граф открываются по очереди на всю ширину в одном пространстве ID. Найдите нормальную форму, выберите толкование русского Викисловаря или введите своё, вручную создайте поля/ветвления, подтвердите контекстные связи между рёбрами и включите миниграф после preview. Повторно выбранные концепты/рёбра сохраняют те же IDs; исследований, копий источников и объединения в активной модели нет.

Операции выполняются через меню узла/ребра/свободного места или кнопку «Действия», подробности — в открываемых формах; нижних рабочих таблиц нет. Направленный контекст между обычными рёбрами показан фиолетовыми пунктирными стрелками с прямоугольным обходом полей; щелчок открывает форму пары. У каждого поля можно добавлять, изменять и удалять внешние словарные обозначения с необязательным источником конкретного значения. Несколько слов могут входить в один ID, одинаковое слово — в разные IDs; правка соответствия сохраняет концепт и его рёбра.

## Запуск

Python 3.11+ и браузер; приложение не требует npm/pip/сборки.

```bat
cd /d E:\Projects\concept-field-lab
start.cmd
```

Адрес `http://127.0.0.1:8765`, данные `local-data\workspace.sqlite3`, остановка Ctrl+C. При открытии прежней SQLite сначала выполняется проверяемый SQLite backup с WAL, затем создаётся пустой постоянный граф. Старые таблицы остаются нетронутыми, исторические исследования не переносятся автоматически. Новый процесс продолжает новое состояние.

[Инструкция оператора](docs/manual/user-guide.md) объясняет поиск значений/IDs, конструктор, общий граф, данные/историю и безопасное восстановление старой базы. [Формат постоянного графа](docs/manual/data-format-permanent.md) сохраняет IDs, происхождение и историю; импорт без старой очереди добавляет точные объекты после подтверждения, повторы пропускаются, конфликты отклоняются. [ADR конструктора M007/M008/M009](docs/manual/definition-builder-architecture.md) сохраняет причины перехода. Локальные формы доступны без интернета; [словарные источники/условия](data/dictionary/NOTICE.md), кэш толкований и ручной ввод сохраняют работу при сбое сети.

## Проверки

```bat
python -m unittest discover -s tests -v
node --test tests/test_graph_view.cjs tests/test_layout.cjs
node tests/cmd-launch.cjs
```

[Отчёт](docs/manual/composition-verification.md) содержит результаты и команды реального Chrome-сценария `tests/permanent-browser.cjs`; Playwright нужен только для тестирования, не для запуска. Тестовые структуры проверяют операции и сохранность, не семантическую истинность. Сцены, активация, извлечение смысла и автоматический выбор маршрутов не реализованы. Следующий UX-этап определяется оператором после первых реальных определений; main этой работой не меняется.
