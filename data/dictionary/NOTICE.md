# Локальный словарь: происхождение и условия

## Толкования M008: русский Викисловарь

Дополнительный источник — [Русский Викисловарь](https://ru.wiktionary.org/), участники проекта, [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Локальный морфологический индекс ниже остаётся отдельным ресурсом. Используется [MediaWiki parse API](https://www.mediawiki.org/wiki/API:Parsing_wikitext) с page / text / revid / redirects; извлекаются только plain-text пункты раздела «Значение» русского языка, без примеров употребления после ◆ и без семантической декомпозиции. Определения иных языков не входят в выдачу. Это адаптация представления словарного текста, с сохранением указания авторства, статьи/редакции и лицензии; производное распространяемое словарное содержание требует ShareAlike.

Каждый выбранный текст сохраняет source: статья, revisionUrl, revision, retrievedAt, license/URL, attribution, responseSha256 и описание преобразования. В черновике сохраняются senseId/entry/lemma и originalText; при ручной правке operatorEdited отличает текст оператора от исходной цитаты. Origins и подтверждённое определение переносят эти сведения в экспорт. Наличие значения не создаёт узлов/рёбер; собственное концептуальное решение не объявляется выводом словаря.

Кэш (`definition-cache/` рядом с базой) содержит только внешние смыслы и происхождение, не концептуальные IDs. Без сети ранее полученные значения доступны; обновление явно запрашивается оператором. Если статьи/значений нет, ответ сообщает об этом и позволяет ручной текст. Максимум ответа 2 МиБ, выдачи — 60 смыслов, timeout urllib 8 с. На Windows при ошибке цепочки сертификатов Python допускается системный curl.exe/Schannel с включённой проверкой TLS и пределом 10 с. В использованной среде этот путь получал реальный MediaWiki ответ; проверки TLS не отключались.

Для сквозной пробы 13 октября 2026 реально получена статья [гайка, редакция 14297625](https://ru.wiktionary.org/w/index.php?oldid=14297625), пять русских значений двух омонимов. Технический выбор рёбер теста не является предлагаемым толкованием. Дата конкретного получения и SHA-256 ответа сохраняются в инженерных свидетельствах M008, а не подменяют текущую редакцию сайта.

## Морфологический индекс M007

Данные: **OpenCorpora**, https://opencorpora.org/, лицензия [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). Авторы — участники проекта OpenCorpora. Производный индекс `lemmas.json` распространяется на тех же условиях: указание авторства, ссылки на источник/лицензию, обозначение изменений и ShareAlike при распространении адаптаций. Это отдельные внешние словарные данные, не лицензирование пользовательских концептуальных графов.

Источник данного снимка — [pymorphy3-dicts-ru 2.4.417150.4580142](https://pypi.org/project/pymorphy3-dicts-ru/2.4.417150.4580142/), OpenCorpora revision 417150, исходный формат 0.92, компиляция 8 января 2022. Упаковочный код имеет MIT; исходные словарные данные сохраняют CC BY-SA. Дата получения пакета: 13 октября 2026. Это фиксированный снимок, актуальность последней версии словаря не заявляется. Прямая загрузка XML 13 октября вернула HTTP 403 / 522; вместо повторения использован доступный пакет.

Изменения: из DAWG перечислены только записи с индексом формы 0, одинаковые пары «нормальная форма / граммемы» устранены. Сохранены 185 215 вариантов различных частей речи. ID — SHA-256 пары (20 шестнадцатеричных знаков); это внешний ключ производного индекса, **не** original lemma ID OpenCorpora и не ID концепта. Предсказания неизвестных слов не запускаются; склонённые формы не включены. Снимок не содержит словарных толкований. Для определения оператор указывает свой текст/источник в черновике.

`provenance.json` фиксирует параметры компиляции, counts, SHA-256 всех файлов пакетных данных и производного индекса. В приложении только стандартная библиотека Python; код pymorphy3 не включён в runtime.

Воспроизведение из корня (зависимости только в игнорируемом каталоге проекта):

```powershell
python -m pip install --target local-data/dictionary-tools pymorphy3==2.0.6 pymorphy3-dicts-ru==2.4.417150.4580142 dawg2-python==0.9.0
python -m scripts.build_dictionary --package-tools local-data/dictionary-tools
```

Проверка SHA-256 `lemmas.json`: `5e52d3d99d86e6fc8606d1e70176f8298b0b78b3aa5a8586982ac94b59d55a47`. Преобразование читает исключительно пакетные данные; словарь не записывается в пользовательскую SQLite и не создаёт узлов. Есть альтернативный вход XML bz2 для скрипта; текущий индекс получен именно пакетным способом.
